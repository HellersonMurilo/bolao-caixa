# bolao-caixa

Site de celular para organizar bolões das Loterias Caixa: o pessoal marca o jogo por um link (sem login), paga pelo Pix e o resultado é conferido sozinho pela API oficial da Caixa.

- `index.html`: o site inteiro (abre direto no GitHub Pages).
- `supabase.sql`: tabelas, regras de acesso e funções do link de convite. Rode no SQL Editor do Supabase.
